# Comandos

## Instalar Angular
npm install -g @angular/cli

## Crear proyecto

### Proyecto con última versión
npx @angular/cli@latest new book-angular


### Proyecto con versión instalada en local

ng new nombre-proyecto

## Versión de Angular
ng version

## Lanzar servidor Angular
ng serve -o

## Crear componente
ng generate component nombreComponente
ng g c nombreComponente

ng g c pages/home
ng g c pages/labs --skip-tests
